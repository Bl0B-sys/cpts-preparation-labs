# CPTS Preparation Labs

Данный репозиториий посвящен подготовке к экзамену **HTB Certified Penetration Testing Specialist (CPTS)**. В нем вы найдете райтапы основных лабораторных работ для подготовки к экзамену

## Основные темы

-   Information Gathering
-   Enumeration
-   Web Application Security
-   Linux Privilege Escalation
-   Windows Privilege Escalation
-   Active Directory
-   Credential Attacks
-   Lateral Movement
-   Pivoting & Tunneling
-   Post-Exploitation
-   Reporting

## Дисклеймер

Все райтапы подготовлены в образовательных целях и основаны на легальных лабораторных работах и ​​учебных средах.
