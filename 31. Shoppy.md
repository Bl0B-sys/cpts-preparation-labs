Монтируем `/root` c папкой `/mnt` контейнера

```
$ docker run -it -v /root:/mnt alpine
/ # ls                               
```

- **`docker run`**: создает и запускает новый контейнер.
- **`-it`**: запускает контейнер в интерактивном режиме и открывает терминал.
- **`-v /root:/mnt`**: связывает (монтирует) папку `/root` с вашего компьютера с папкой `/mnt` внутри контейнера.
- **`alpine`**: использует легкий и быстрый образ операционной системы Alpine Linux.
- **`/ # ls`**: это не часть вводимой команды. Символ `/ #` показывает, что вы уже находитесь внутри контейнера как суперпользователь (root), а `ls` — это команда просмотра файлов.

```
~ # cd /mnt                     
/mnt # ls                       
root.txt                        
/mnt # cat root.txt             
a1033b67d939bea5552a70649c7e27a9
/mnt #
```
