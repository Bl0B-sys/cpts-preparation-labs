Мы можем загрузить `.scf` файл, который выполнит обратное подключение к нашей машине, и мы сможем получить NTLM-хэш. 

> [!NOTE] Файлы `.scf` 
> Файл с расширением .scf — это чаще всего командный файл проводника Windows (Windows Explorer Shell Command File), который используется для автоматизации определенных действий в операционной системе.
> 
> Это своего рода ограниченный скрипт, который выполняет команды связанные с файловой системой Windows
> 
> Когда любой другой пользователь сети открывает эту папку через свой Проводник (Windows Explorer), система начинает подгружать иконки для всех файлов в ней
> 
> Если внутри файла в строке `IconFile.scf` указан путь к удаленному серверу (например, `\\192.168.1.50\share\image.ico`), компьютер пользователя попытается подключиться к этому IP-адресу по протоколу SMB, чтобы забрать картинку.
> 
> В процессе этого подключения Windows автоматически отправляет в сторону удаленного сервера Net-NTLM хэш пароля текущего пользователя сети. Злоумышленники используют эту особенность на сетевых папках для перехвата (фишинга) учетных данных сотрудников в корпоративных сетях.
