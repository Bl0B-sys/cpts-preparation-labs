В личной папке пользователя находим директорию `passpie`
![Pasted image 20260616145203](./screenshots/Pasted%20image%2020260616145203.png)

Passpie это хранилище для паролей, для доступа к паролям при этом используется парольная фраза. 

![Pasted image 20260616145309.png](./screenshots/Pasted%20image%20260616145309.png)

При этом passpie использует GnuPG. GnuPG использует пару приватного и публичного ключа для шифрования. Для нас важно то, что из приватного ключа, мы можем извлечь хэш пароля. 

> [!NOTE] Примечание
> Из приватных GPG ключей, можно вытаскивать хэш пароля, и после этого использовать его для брутфорса

![Pasted image 20260616150006](./screenshots/Pasted%20image%2020260616150006.png)

Нам понадобится только приватный ключ. Мы прогоняем этот ключ через `gpg2john` для получения хэша

```
gpg2john keys > keys.hash
```

После чего полученный хэш ломаем с помощью `john`

```
john -wordlist=/usr/share/wordlists/rockyou.txt keys.hash --format=gpg
```

И получаем пароль от хранилища
